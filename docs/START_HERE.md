## Getting Started (5 Minutes)

### Step 1: Compile (1 min)
```bash
cd CPPBankProject
make
```

### Step 2: Run (1 min)
```bash
./BankSystem
```

### Step 3: Try the menu (3 min)
```
1 → Create a customer
2 → List all customers
3 → Function Pointer Demo (BinaryIntOp callbacks)
4 → Exit
```
